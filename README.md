# Y-Boutique

Maquette de boutique en ligne de **matériel informatique** : catalogue, panier, tunnel de commande en 3 étapes (informations, adresse, paiement) et confirmation.

## Contenu

- `index.html` : interface complète (HTML, CSS et JavaScript intégrés).
- Le JavaScript appelle `api.php` pour les données. **Ce fichier n'est pas dans le dépôt** : sans lui, le catalogue et la commande ne fonctionnent pas.

## Lancer

Servir le dossier avec un serveur PHP (par exemple `php -S localhost:8000`) qui fournit `api.php`.
